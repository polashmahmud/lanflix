# LanFlix

A desktop movie and TV library for LAN movie servers. LanFlix reads the server's folders, shows every movie and
show with posters and details, and plays them in VLC. Nothing is downloaded: videos stream straight from the server.

**[Download the latest version](https://github.com/polashmahmud/lanflix/releases/latest)**

## Install

**Windows:** download `LanFlix_x.y.z_x64-setup.exe` from the [latest release](https://github.com/polashmahmud/lanflix/releases/latest)
and run it. If SmartScreen warns about an unknown publisher, choose *More info → Run anyway*.

**macOS:** not available for the current version yet.

You also need:

- [VLC media player](https://www.videolan.org/vlc/)
- A connection to the LAN movie server (your ISP's network)

## Updates

LanFlix checks for new versions by itself. You can also check from **Settings → About → Check for updates**.
Updates install from inside the app, so you only need to download the installer once.

## Getting started

1. Open LanFlix. If the DhakaFlix server is reachable, its movie and TV folders are added automatically.
2. To add more, open the server in your browser, copy a category folder link, and paste it in
   **Settings → Sources**.
3. Wait for the first sync to finish, then browse, search and press Play.

## Features

- Home rows, a full library, and fast search that forgives typos (`Avngers`) and initials (`LOTR`)
- Filters for year, quality (4K, 1080p…), platform, Dual Audio and genre
- TV shows with seasons, episodes, watched marks and **Continue** to the next episode
- Movie info: posters, summary, rating, cast and trailers (with a free TMDB key)
- Bangla and English subtitles from OpenSubtitles and SubDL
- Watchlist, recently played and "Because you watched" suggestions
- Play on your phone with a QR code, or use your phone as a remote
- Cast to a DLNA smart TV or Chromecast / Google TV
- Backup and restore your library, settings and watch history
